### Análise de Compras
<img align="right" width="500"  src="https://github.com/MayconJhonatan/Portfolio_Compras/blob/main/Desing/Dashboard%20de%20compras.png?raw=true">
Projeto desenvolvido para análise das compras de uma empresa de produtos eletrônicos, utlizando linguagem SQL para consulta ao banco de dados e Power BI para a construção do Dashboard.<br>
Principais desafios enfrentados: <br>
- Desenvolvimento de consultas eficiêntes utilizando linguagem SQL.<br>
- Aplicação de estatística descritiva  para identificar as principais demandas das compras na base de dados.<br>
- Desenvolvimento de métricas utilizando linguagem em DAX.<br>
- Medição da performance e da variação das compras ao longo do tempo, com a identificação das principais causas de recompras fora de época promocional.
